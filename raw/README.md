# Raw

Every source, as it arrived. Nothing here is edited after it lands, and nothing
here is deleted. A page is one reading of a source. This folder holds what the
reading came from, so a later reader can check it.

| Folder | What is in it |
| --- | --- |
| `videos/<slug>/` | YouTube: `audio.mp3`, `transcript.txt`, `metadata.md` |
| `articles/<slug>/` | Web pages, saved as markdown |
| `files/<slug>/` | Documents: PDFs, spreadsheets, anything with no other folder |
| `transcripts/<slug>/` | Recordings: the audio, the transcript, `metadata.md` |
| `photos/<slug>/` | Pictures, with the caption that came with them |
| `notes/` | Short notes, one file each |

`dropbox/` is an ingest path, the same as a YouTube link. A file that arrives
there is a source, so it is copied here before it is filed. The `dropbox` skill
has the table that says which folder each kind of file goes to.
