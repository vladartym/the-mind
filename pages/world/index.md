# World

Other people's work. Read this first when you answer a question about a
source, a person, a tool or an idea.

Nobody in this area knows the user. For the people the user sees, read
`pages/self/index.md`. For the user's clients and builds, read
`pages/work/index.md`.

Add a heading for each folder when the first page in it is written, such as
`## Sources`, `## Concepts`, `## Tools`, `## People`. Put one line under it for
each page: a link and a one-line summary.
